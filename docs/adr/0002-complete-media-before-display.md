# ADR 0002：每张照片原图和缩略图就绪后才入库显示

日期：2026-10-13。状态：设计阶段采用，尚未实现。替代 ADR 0001 的渐进下行与访问优先级条款，其余架构决策保持有效。

## 背景

用户要求首版放弃缩略图先显示/原图后台补齐，改为原图和缩略图下载完成后再显示，以最大化复用当前 PhotoViewer。

当前应用以本地文件入库，宫格请求 ThumbnailLoader，详情已有本地预览和原图解码。允许未下载原图进入图库会扩大数据模型、UI 和操作分支。

## 决策

- 上传继续包含原图和缩略图，服务端成对绑定与增量协议不变。
- 下行中间状态只保存在同步清单/待办；每张照片双资源校验、稳定发布和缓存映射完成后入库。
- 沿用本地路径、MediaItem、宫格、详情和本地操作；增加缩略图导入及双资源发布屏障。
- 首版不增加网络访问优先级、远端占位或预览可见的独立状态。
- 更新采用完整版本切换，失败继续显示旧完整版本。

## 代价

新照片首次出现在图库需要等待原图完整下载；大图及低带宽环境等待更长。本地空间按原图完整同步预算。换来更少的 UI/数据模型改动与更小的接入范围。

未来恢复渐进下行需要独立任务，不能在当前接入中隐式加入。
